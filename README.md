# 铁旅 · 中国高铁模拟旅程 (Train Journey)

一款单文件、零依赖的**中国高铁旅行模拟游戏**。基于 12306 真实车次数据，选择车站、买票上车，沿真实经停站行驶，体验窗外风景、报站广播、餐车点餐、夜行星空，收集 16 项铁路成就，书写旅程手账。

## 🚄 玩法

- **线路面板**（紧凑两列网格 + 拼音搜索，无地图、无折叠）：7 条中国高铁线路**全部展开**
  - 🔴 **京沪高速线**（19 站 / 1318 km）· 北京南 ⇄ 上海虹桥
  - 🟣 **京广高速线**（25 站 / 2298 km）· 北京丰台 ⇄ 广州南
  - 🟠 **京沈高速线**（6 站 / 697 km）· 北京朝阳 ⇄ 沈阳
  - 🔵 **哈大高速线**（11 站 / 921 km）· 哈尔滨西 ⇄ 大连北
  - 🟢 **徐兰高速线**（14 站 / 1406 km）· 徐州东 ⇄ 兰州西
  - 🟡 **沪昆高速线**（24 站 / 2252 km）· 上海虹桥 ⇄ 昆明南
  - 🩵 **杭深线**（14 站 / 1450 km）· 杭州东 ⇄ 深圳北
  - 共 107 座车站、6 个换乘站（沈阳 / 徐州东 / 上海虹桥 / 郑州东 / 长沙南 / 杭州东）
- **真实车次数据**（来源：12306 全量 G/D 车次经停表，2026-06-17）：**3530 趟真实车次**经过本项目 107 站，含跨线车次（例：G101 北京朝阳→哈尔滨西 跨京沈+哈大；G1341 上海虹桥→娄底南 跨沪昆）
- **双槽位选站（购票软件标准模式）**：顶栏"出发站 ⇄ 到达站"双输入框，点第一个站自动填出发并切到到达槽，点第二个站自动填到达
- **真实可达性联动**：选出发站后，到达站列表自动基于"存在某真实车次同时停靠两站"判定——不可达的站灰色置灰，可达站高亮
- **拼音首字母搜索**：🔍 输入框支持「bjn=北京南」「shhq=上海虹桥」「杭州」汉字子串，实时过滤
- **紧凑网格**：每条线所有站点两列排布，**全部展开不折叠**，按钮颜色——金色=已选 / 绿色=已到访 / 金色换乘 ◎ / 灰色=不可达
- **真实车次列表**：A→B 直达的所有真实车次按时分排序，显示 12 个 + "展开全部 N 趟"按钮；如北京南→上海虹桥 38 趟
- **席别与计价**（大圆距离 ×1.15 计价）：二等座 0.42 元/km · 一等座 0.70 · 商务座 1.33
- **行程引擎**（站序驱动，支持跨线车）：报站/里程/scenary 按真实经停站序列
- **顶栏实时显示**「🚉 下一站 XXX」+ 里程 + 时刻 + 时速
- **8 种窗外风景**（城市天际线 / 平原 / 江南水乡 / 山景 / 林海雪原 / 海岸 / 黄土高原 / 喀斯特）随区段切换
- **报站广播**：文字横幅 + Web Speech API 中文语音（可关）
- **倍速**：1x / 4x / 16x / 暂停 / 直达终点
- **车内互动**：餐车点餐（6 种餐品，随机售罄）、拍窗外风景（5 秒 CD，70% 成功率）
- **中途下车**：可在任意站点"下车结算"，区间 = 出发站 → 最近经过站
- **经济**：初始 ¥3000；票价支出、餐车消费；成就解锁现金奖励
- **16 项成就**：首乘、500/2000/8000/20000 km 里程里程碑、线网达人、车次收藏家、全席体验、美食家、摄影师、夜行者、驿站行者、京沪/京广/哈大全程、连环旅人
- **存档**：localStorage 自动保存（可随时重置）
- **铁路网拓扑图**：7 条线、换乘站共用节点；站名按"奇偶错位"标注避免重叠；线路色彩与车次/线网视觉统一

## 🚀 本地运行

直接双击打开 `index.html` 即可，单页 + `data.js`，零依赖、无需构建。

- **单元/集成测试**（jsdom）：`smoke_test.js` — 77 个断言覆盖数据完整性、购票、行驶、报站、到站结算、中途下车、存档读档、真实 DOM 点击流程

## 🎨 设计规范（项目记忆 · 必须遵守）

### 禁止页面字体颜色过多
- 页面文字颜色**默认只用三种灰阶**：`--text`（主文字）/ `--dim`（次要）/ `--faint`（弱化）。
- 彩色文字**仅限四种用途**，不得用于装饰、标题、数据：
  - 金色 `--gold`：唯一"选中 / 已达成"强调色（选中站点、激活导航、已打卡/已解锁、到账金额）
  - 绿色 `--green`：仅"已完成 / 达标"状态
  - 蓝色 `--blue`：仅可点击链接 / 下一步主操作
  - 红色 `--red`：错误 / 危险
- **禁止**为数字、标题、正文随意添加彩色；新增文字一律先考虑灰阶。
- 未在 `:root` 定义的色值（如 `--purple`、`--orange` 文字）不得使用。

### 禁止渐变背景
- 所有背景一律**纯色**（`--bg`/`--panel`/`--panel2`/`--border` 或固定色值）。
- **禁止** `linear-gradient` / `radial-gradient` / `repeating-*gradient`（含按钮、横幅、卡片、进度条、装饰元素）。

### 禁止圆弧卡片样式（直角优先）
- 卡片 / 面板 / 按钮 / 输入框一律**近直角**：`border-radius` 统一为 `4px`（容器级 `6px`），**禁止大圆角**（≥10px）与"胶囊/药丸"形按钮。
- 仅两类允许圆形（`border-radius:50%`）：开关按钮的滑块、印章/图例的圆点等**功能性小圆点**，不得用于卡片或按钮外形。
- 新增任何容器/控件默认按直角处理，不要复刻圆角风格。

### 默认浅色背景
- **默认浅色**：`:root` 浅色变量为默认，仅当用户主动切换（设置→深色模式，写 `settings._themeChoice`）才进入深色。
- 旧存档若 `dark:true` 且无 `_themeChoice` 标记，加载时自动迁移为浅色。
- 页面 `theme-color` meta 与默认背景保持一致（浅色 `#f4f6f8`）。

### 不同分辨率适配
- 响应式断点按屏宽收敛：`>1024px` 桌面全列 → `≤1024px` 站点栅格 8→6 列 → `≤660px` 手机竖屏（站点 6→4、印章 10→5 等）→ `≤400px` 极窄屏（站点 4→3、印章 5→4 等）。
- 新增模块必须给出多断点栅格收敛方案，禁止只在单一分辨率下正常。
- 所有用色需主题感知：禁用写死深色（如 `#1a2029`/`#232b38`/`#3a4052`）作为前景/背景，统一走 CSS 变量（`--track`/`--unk`/`--blue-tint` 等）。

### 全服排行 ticker（顶部翻页条）
- 顶部单行**竖向翻页**：一条一条淡入淡出循环切换，**禁止横向滚动跑马灯**。
- 效果必须**非常克制**：纯淡入淡出 + 轻微纵向位移（≤7px），时长约 0.45s，停留约 3s，无放大/发光/变色等夸张动画。
- 当前全量循环；后续接入真实数据后按优先级排序（自己的成绩/好友动态优先）。

### 移动端竖屏（手机优先）
- 新增布局必须考虑窄屏（<660px）：栅格列数需随屏宽收敛（如站点 8→4 列、印章 10→5 列）。
- 顶部保持干净：品牌标题只放页面底部 SEO 区，顶部只保留 HUD 统计与全服排行 ticker。
